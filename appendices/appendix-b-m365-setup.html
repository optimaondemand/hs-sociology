APPENDIX B
M365 Setup and File Organization
Set this up once, in your first week, and every later submission takes thirty seconds instead of ten minutes. This guide works whether you are starting the course on day one or joining mid-year.
🔑 ACCESSING YOUR SCHOOL M365 ACCOUNT
  1. Go to portal.office.com and sign in with your Optima Academy school email address, not a personal Microsoft account. Every course file must live in your school OneDrive, because that is the only account Canvas can reach.
  2. From the Microsoft 365 home page you can open Word, PowerPoint, Excel, and OneDrive directly in the browser. You may also download the desktop applications if you want the fuller feature set; either one works for this course.
  3. If your school account will not sign in, do not switch to a personal account as a workaround. Files saved there cannot be submitted through the Canvas integration, and you will have redone the work for nothing. Go to the technical help section below instead.
📁 YOUR ONEDRIVE FOLDER STRUCTURE

In your school OneDrive, build this structure if it does not already exist. Open OneDrive in the browser, create a new folder, and nest the next one inside it, repeating until you have all three levels.

OneDrive (school account)
Optima
Sociology
Sociology_2025-26 (every file you submit this year goes here)
📝 FILE NAMING CONVENTION

Every file you submit in this course follows one pattern:

LastName_FirstName_AssignmentName_SOC12[_Draft1 / _Final]

For example:

  • Johnson_Maria_ThinkerProfile_SOC12_Draft1
  • Johnson_Maria_ThinkerProfile_SOC12_Final
  • Johnson_Maria_InstitutionStudy_SOC12_Final
  • Johnson_Maria_CaseStudy_Weber_SOC12_Final
  • Johnson_Maria_FlourishingCapstone_SOC12_Final

Never overwrite a draft. Save each new draft under its own name, _Draft1, then _Draft2, so your revision history stays intact. Your submitted version is always the one and only file labeled _Final. Keep every draft and final in your Sociology_2025-26 folder.

✅ SUBMITTING THROUGH CANVAS
  1. Open the assignment in Canvas and select Submit Assignment.
  2. Select the Microsoft OneDrive tab if it is available, or upload the file directly.
  3. Navigate to Optima → Sociology → Sociology_2025-26 and select your file.
  4. Select Submit, then confirm you see the submission confirmation before you close the tab. A file you never confirmed is a file the gradebook does not know about.

💡 TECHNICAL HELP
If you have trouble accessing your school M365 account, contact Optima Academy technical support at the email or phone number in your student handbook. Do not switch to a personal Microsoft account as a workaround. Files kept in a personal account cannot be submitted through the Canvas integration, no matter how the file itself looks, so the workaround costs you time rather than saving it.
