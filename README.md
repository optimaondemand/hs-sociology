# HS Sociology Honors (Florida 2108300)

Optima Academy Online. GitHub-hosted course content for HS Sociology Honors.

One semester, 0.5 elective credit, grades 9-12, fully asynchronous Canvas plus VR.

## What is here

- `week-01/` to `week-18/` — module map, two lesson pages, and two primary source guides per week
- `_widgets/` — four self-contained interactive widgets, iframed by the lesson pages via relative paths
- `appendices/` — five reference pages

These are ungraded in-lesson content pages. Everything graded (quizzes, assignments,
discussions, module wrappers) is Canvas-native and lives in the Canvas course, not here.

## Important

The lesson pages iframe the widgets by **relative path** (`../_widgets/...`).
The directory structure must be preserved or the widgets break.

Seven primary source guides carry a visible PLACEHOLDER block marking text that could not
be embedded or precisely located. These must be resolved before the course is published to students.
